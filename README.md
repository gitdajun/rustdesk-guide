# RustDesk 详细安装与使用指南

RustDesk 是开源远程桌面软件，可走公共服务器或自建 ID/中继服务器，客户端覆盖桌面与移动平台。

- 源码：https://github.com/rustdesk/rustdesk
- 客户端下载：https://github.com/rustdesk/rustdesk/releases
- 服务端相关说明见官方文档与 `rustdesk-server` 仓库

---

## 一、安装客户端

1. 打开 Releases 页面，下载与系统匹配的安装包：
   - Windows：`.exe` / 安装器
   - macOS：`.dmg` 等（注意系统安全设置里允许运行）
   - Linux：按发行版选 `.deb` / `.rpm` / AppImage 等
   - Android：APK 或应用商店渠道（以官方说明为准）
2. 安装后启动，界面会显示 **ID** 与 **密码**（可改成固定密码）。

两边都要装客户端：被控端开着、主控端用来连进去。

---

## 二、最快上手（公共服务器）

适合个人临时协助：

1. 被控端把 **ID** 发给你（可再设「永久密码」避免每次改）
2. 主控端输入 ID → 连接 → 输入密码
3. 连接成功后可控制键鼠、视情况传文件（以版本功能为准）

注意：

- 仅连接你信任的人；密码不要发到公开群
- 公共服务器延迟与可用性不保证
- 公司设备需遵守信息安全制度

---

## 三、自建服务器（推荐给长期使用）

自建一般包含：

| 组件 | 作用 |
|------|------|
| hbbs | ID 注册与信令 |
| hbbr | 流量中继（打洞失败时走中继） |

### 部署概要

1. 准备一台有公网 IP 或可端口转发的 Linux 服务器
2. 按官方 `rustdesk-server` 文档安装 hbbs/hbbr（Docker 或二进制）
3. 开放文档要求的端口（常见涉及 TCP/UDP，以当前文档为准）
4. 启动后记下 **Key**（公钥）与服务器地址
5. 在客户端「设置 → 网络」中填写：
   - ID 服务器
   - 中继服务器（可与 ID 同机）
   - Key
6. 主控端、被控端都配置同一套服务器后再连接

### 运维建议

- 用防火墙限制来源 IP（若仅公司使用）
- 定期升级服务端与客户端
- 监控磁盘与带宽（中继流量可能较大）
- 不要把 Key 与管理端口暴露给不明来源

## 四、功能向导

| 功能 | 说明 |
|------|------|
| 远程控制 | 桌面操作 |
| 文件传输 | 视版本与权限开关 |
| 音频 | 可能可选，视平台 |
| 剪贴板 | 双向同步视设置 |
| 无人值守 | 固定密码 + 开机启动 |

被控端可设置：开机自启、密码强度、是否接受来自局域网的连接等。

---

## 五、网络与体验

- 两边 NAT 严格时可能必须走中继，速度取决于服务器带宽
- 公司网络可能拦截未知 UDP/TCP，需网管放行或走 VPN
- 尽量让被控端使用有线或稳定 Wi-Fi

---

## 六、常见问题

| 现象 | 排查 |
|------|------|
| 连不上 | ID 是否填错、密码错误、被控端离线、服务器地址/Key 不一致 |
| 能连但极卡 | 中继带宽不足、跨运营商、被控端性能差 |
| 仅局域网可以 | 公网端口未开、云安全组未放行 |
| macOS 无控制 | 辅助功能/屏幕录制权限未授予 |
| 安全软件拦截 | 加白名单 |

---

## 七、安全与合规

- **必须获得被控方明确授权**
- 勿用于未授权入侵或监控
- 远程结束后可关闭被控端软件或改密码
- 遵守当地法律与公司制度
